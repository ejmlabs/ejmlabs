ejmlabs application kit 1.0.0

One theme for every interface we ship.

The desktop IDE, the terminal app, editors and terminals all read the same roles. Edit theme.json, run node scripts/build-ui.mjs, and every file below follows. Use the switch to see both themes.

Roles

Surfaces step up from ground to overlay. Text has four steps. Primary and accent come from Sage. Status, special and diff colors are kit additions, tuned for 4.5:1 on every surface.

Application shell

An IDE with an agent beside the editor. Regions are told apart by tone, selection is a tint with a small primary marker, and tool calls are soft cards with a visible state. Under 760 px the sidebar stacks above the editor.
