ejmlabs application kit 1.0.0

Terminal building blocks.

Every part of a terminal app, rendered at 80 columns with the exact characters that rust/ejm_tui.rs produces. Choose parts from this page instead of inventing new ones. The rules for each part are in the terminal guide. Use the switch for dark, light and the NO_COLOR look.

 accent  dim  warning  error  success  special  bold  selected  plain

Header

Two lines at the top of every screen. Line 1 names the app, provider and session. Line 2 shows what the app may do (grants), where, and the short session id. Grants turn warning when write or shell is on.

Helper and roles

Helper header_lines Roles accent bold, plain, dim, warning

Transcript block

The conversation. A title line, then the body, then one blank line. Use it for every message, tool call, notice and error. Code fences, diffs and tool output break by column; prose breaks at spaces.

Helper and roles

Helper transcript_block Roles accent, bold, dim, warning, error, success, special

Status line

One line above the composer: counts, then the run state. Accent while work runs, dim when idle. Counts drop from the right when the line is too narrow; the run state always stays.

Helper and roles

Helper status_line Roles accent, dim

Composer

Where the user types. A rounded box with the accent border, a title, and a prompt glyph. It grows to six text lines, then scrolls. The terminal cursor sits after the last typed character.

Helper and roles

Helper composer_block, composer_rows, composer_layout Roles accent, dim, plain

Key hints

One dim line of Key action pairs. List the most important pair first: pairs that do not fit are dropped from the end.

Helper and roles

Helper hints, hints_text Roles dim

Overlay picker

A centered box over the screen for choosing one item, such as a session. The title carries the keys. The selected row is reversed accent. Esc closes it.

Helper and roles

Helper popup, titled_block, list_row Roles plain, dim, selected

List

Rows of a label and a dim detail, with one selected row. The same row an overlay picker uses, without the box.

Helper and roles

Helper list_row Roles plain, dim, selected

Table

Fixed-width columns with two spaces between. Numbers are right aligned. Long text is cut with an ellipsis. A header row is the same function with the dim style.

Helper and roles

Helper table_row Roles dim, plain

Progress

A determinate bar in plain ASCII, so it needs no glyph fallback, and a list of steps with a status glyph each. The bar turns success at 100 percent.

Helper and roles

Helper progress_bar, progress_line, step_line Roles accent, success, error, dim

Spinner

One spinner while work runs, 80 ms per frame, and nothing when idle. With reduced motion it is the static running glyph.

Helper and roles

Helper spinner_frame Roles accent

Banner

A one-sentence notice or error with a glyph. Long text wraps with a hanging indent under the first word.

Helper and roles

Helper banner Roles warning, error

Key-value

A dim key in a fixed column, then the plain value. For session details, settings and help text.

Helper and roles

Helper kv_line Roles dim, plain

Tabs

A row of labels to switch between views. The active tab is reversed, so it is visible without color.

Helper and roles

Helper tabs_line Roles selected, dim

Diff

File headers are dim, hunk headers use the special role, added lines are success and removed lines are error. The first character always carries the meaning too.

Helper and roles

Helper diff_line, diff_style Roles dim, special, success, error

Prompt and confirm

A single question on one line. Confirm shows the default in capitals. A prompt shows a dim hint until the user types.

Helper and roles

Helper confirm_line, prompt_line Roles accent, plain, dim

Empty state

What shows before the first message: a bold accent title, then dim lines that say what to do.

Helper and roles

Helper empty_state Roles accent bold, dim

Error state

Says what failed, then what to do next, both in the error style. The session stays open.

Helper and roles

Helper error_state Roles error

Too small

Below 20 columns or 8 lines, show only this text and nothing else.

Helper and roles

Helper too_small, too_small_lines Roles plain

Chat agent screen

Header, transcript, status line, composer and hints, top to bottom, at 80 by 22. This is the ejm-cli screen built from the helpers.

Helper and roles

Helper all of the above Roles all

Plain mode

The same screen under NO_COLOR with ASCII glyphs. Color is gone, bold carries accent, warning and error, and every state still has a word or a glyph.

Helper and roles

Helper Theme::no_color, glyph_set(true, _) Roles bold, plain
