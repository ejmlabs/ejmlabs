Build with the kit

Copy the kit, load three style sheets, and build pages from named parts. You write no CSS, and the same parts follow the light and dark theme on their own.

Getting started

The kit is a folder. There is no package to install and no build step to run for a site. Copy design-kit into your project, keep its files together, and open web/starter.html to see a whole page built from the parts.

Note

Each project repository carries its own copy of the kit. Re-copy the folder when the kit changes, then run the page checker again.

Load the kit

A page uses exactly three style sheets, in this order. The page carries no <style> block and no inline styles.

Add the head scripts

The theme script is synchronous on purpose: it sets the saved theme before the first paint, so the page never flashes the wrong one. The docs script is deferred and only adds behavior on top of a page that already works.

Design tokens

Tokens are CSS custom properties from tokens/brand.css. The parts read them, so a site uses them by choosing a part, not by writing a value. Spacing runs on a 4px base and an 8px grid.

Spacing and radius tokens
TokenValueUse it for
--ejm-space-28pxThe smallest gap between related items.
--ejm-space-416pxThe gap inside a control or a small group.
--ejm-space-624pxThe gap between paragraphs and blocks.
--ejm-space-1248pxThe gap between groups on a page.
--ejm-radius-medium12pxInputs and code blocks.
--ejm-radius-large24pxPanels, cards, callouts and terminals.
--ejm-radius-pill999pxButtons, tags and the menu.

Type uses two families. Manrope sets text. IBM Plex Mono sets names, code and values, such as token names and file paths.

Using components

Start from the need, not the class. web/patterns.html shows every part live next to the line that says when to use it and the exact markup. Copy the markup and change the words.

  • Build a page from bands. Each band holds one heading and one kind of content.
  • Use tone and space to separate groups. Do not put a border around a card or a callout.
  • Keep at most three items in a row. Four settle into two by two.

Tip

Every callout begins with its label written out: Note, Tip or Warning. Meaning never depends on the fill alone.

A warning callout looks like this in markup. The label comes first, then the sentence the reader must not miss.

Theming

Dark is the default for applications, and light mirrors it. Both start from the brand palette, with Sage leading. Colors are defined once, in ui/theme.json, and generated into every target.

Warning

Never edit a generated file by hand. Change ui/theme.json and run node scripts/build-ui.mjs. For the site style sheet, edit a part in web/parts/ and run node scripts/build-web.mjs.

Read a theme role

Use a role by name and never a literal color. The same role exists for the web, for editors and for terminal apps.

Checking your page

Two scripts keep a page honest. The page checker verifies that a page uses the kit properly. The screenshot script shoots a page at every size in the device matrix, from a 320px phone to a 5120px super ultrawide, and reports horizontal overflow.

Options of shoot.mjs
OptionValueDefaultWhat it does
--outdirtemp folderWhere the PNG files go.
--onlya,bevery sizeRuns only these names from the matrix, such as laptop,iphone-mini.
--themedark | lightsystemSets the theme and emulates the matching color scheme.
--fullflagoffSaves the whole page as strips of up to 2400 CSS px.
