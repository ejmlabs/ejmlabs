ejm-cli

A terminal coding agent.

Send a prompt and watch a tool call stream in. File tools are read only until write access is granted, and the header shows the grant.

Simulated demo. Nothing runs on your machine and nothing is sent anywhere. Turn on JavaScript to send your own prompt.

ejm-harness

Many sessions, one governor.

Queue sessions, change the limit, and crash the worker. Every transition lands in an append-only journal, and recovery replays it.

#001  +0.00s  engine.start  limit 3, command slots 2
#002  +0.00s  session.queued  session-a1
#005  +0.25s  session.admitted  session-a1 (1/3 running)
#031  +4.50s  worker.crashed  3 running sessions interrupted
#036  +4.50s  recovery.replay  replayed 9 events for session-a1
#040  +5.50s  session.resumed  session-a1

Simulated demo. Counts, timings and event names are illustrative sample values. Turn on JavaScript to run it.
