projects

A coding agent engine, and two ways to use it.

ejm-harness is the engine. ejm-cli and ejm-ide are separate apps built on it. All three are open source under the MIT license.

  • ejm-cli

    A coding agent for your terminal. It streams the conversation, saves sessions, and lets you steer a running turn.

    TerminalRustMIT

  • ejm-ide

    A desktop IDE with an agent beside the editor. Each tool call and the diff it made stay in view.

    DesktopTauriRust

  • ejm-harness

    A reusable Rust engine for coding agents, with typed TypeScript and Python APIs. It powers the other two.

    EngineRustPython

approach

Each project starts as a question and ends as something you can use.

We keep experiments small so they can be built, tried and judged quickly. What we build for ourselves, we release as open source.

  1. Start small.

    Each experiment answers one question, so it can be built, tried and judged quickly.

  2. Make it useful.
