site kit

One choice. Every site.

Light and dark, the same toggle in the same place, remembered across every ejmlabs.com site.

toggle

Try the toggle.

The button at the far right of the header and the one below do the same thing. The label stays "Dark mode"; the pressed state says whether it is on. The choice is saved and the page keeps it on reload.

The two buttons use data-theme-set, which sets a theme directly. Add ?theme=dark to the address to see a theme without saving it.

surfaces

The same parts, both themes.

Each pane shows its own theme whatever the page is set to. Sage panels and bands, Forest and Ink keep their brand colors in both. Everything else moves to the application theme roles.

contrast

Measured, not judged by eye.

Ratios come from a script that reads the real color values. Text needs 4.5 to 1. Large type and field borders need 3 to 1. Every pair passes. The sample column shows the pair as the text color on its ground.
