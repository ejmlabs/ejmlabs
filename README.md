# ejmlabs

## Overview

The ejmlabs brand guide, design kit, and studio website at [ejmlabs.com](https://ejmlabs.com/). The design kit supplies the shared site, desktop, web, and terminal components for the projects.

## Status

This repository holds studio source and brand materials. Source version 0.1.0 is a development baseline. Consult [releases](https://github.com/ejmlabs/ejmlabs/releases) for actual published artifacts. Brand material has its own rights and is not licensed as an MIT software product.

## Requirements

Node.js 24 LTS and npm. Python 3 is useful for the local static preview. The design kit uses checked generated files and bundled font notices.

## Quick start

```sh
git clone https://github.com/ejmlabs/ejmlabs.git
cd ejmlabs
node design-kit/scripts/check-kit.mjs
npm --prefix site test
npm --prefix site run build
npm --prefix site run preview
```

The preview listens only on 127.0.0.1:4827. Private source requires GitHub access until publication.

## Usage

Start with [the design kit](design-kit/README.md). Use [site components](design-kit/SITES.md) for websites and [the application kit](design-kit/UI.md) for apps. [The studio site](site/README.md) uses those components. `x-kit/` contains the social profile kit. `ejmlabs-design-kit.zip` is generated by the site build into site/dist and is not a committed release.

## Development

```sh
node design-kit/scripts/build-ui.mjs
node design-kit/scripts/build-ui.mjs --check
node design-kit/scripts/check-kit.mjs
npm --prefix site test
npm --prefix site run build
```

Use the OpenSpec workflow for feature and bugfix changes. Keep generated assets and their source definitions consistent. Human admission controls CI and AI runs; see the contributor guide. A successful local build does not deploy the site.
