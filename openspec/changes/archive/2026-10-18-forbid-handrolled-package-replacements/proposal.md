# Proposal

## Why

Project guidance must forbid rebuilding functionality that trusted, maintained packages already provide. It must also require useful tests and leave each area better after work.

## What Changes

- Add a root `AGENTS.md` with the three engineering rules and the existing writing and OpenSpec requirements.
- Put the same explicit package, test-value, and campground rules in all six project skills.
- Preserve skill metadata, workflow instructions, and unrelated edits.

## Capabilities

### New Capabilities

- `agent-engineering-policy`: consistent package reuse, test value, and local cleanup rules in project instructions.

### Modified Capabilities

None.

## Impact

This changes agent guidance and its OpenSpec record. It adds no runtime dependencies or product behavior. Verification covers instruction coverage, skill validity, and OpenSpec validity.
