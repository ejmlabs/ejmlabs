# Proposal

## Why

CLI, IDE, and Harness need distinct logos that belong to the ejmlabs family. The design kit currently supplies the studio logo to all three projects.

## What Changes

- Add three project symbols based on the studio mark's flowing ribbons, open forms, and rounded ends.
- Pair each symbol with its lowercase project name using the existing Manrope font.
- Supply editable SVGs, transparent PNGs, single-color variants, and square icons in the existing palette.
- Add a family preview, usage guide, and repeatable exports under `design-kit/projects/`.

## Capabilities

### New Capabilities

- `project-identity`: Distinct CLI, IDE, and Harness logos with shared brand rules and portable exports.

### Modified Capabilities

None.

## Impact

Adds project artwork and its export script to the canonical design kit. Uses the existing fonts, HarfBuzz/fontTools outline helper, and librsvg renderer. The studio logo source stays authoritative. Application and website integration is outside this asset-design change.
