# Proposal

## Why

Public contributors need current guidance and a site that offers only maintained
material. Obsolete handoffs, duplicate social kits, and archive downloads add
confusion and upkeep while the shared UI owner migration remains open.

## What Changes

- Remove the obsolete redesign brief and correct source ownership guidance.
- **BREAKING:** Retire kit ZIP offers and generation, the X kit pages, and the
  swag gallery. Do not publish their remaining files or offer replacement kits.
- Remove three committed ZIPs, both copies of the X kit source and handoff
  files, and five unused kit generation, preview, and verification helpers.
- Keep active site CSS, JavaScript, fonts, icons, motifs, headers, notices, and
  provenance unchanged. Retain the remaining rendered X and swag files for
  separate bounded removals, outside the generated site.
- Install reviewed shared workflow callers and a pinned public `ejm-ui` source
  manifest, with the exact old and new workflow sources for static review.
  Supply the exact UI install manifests, full lockfile, and license as separate
  static review data until trusted preparation can supply the installed pin.
  Keep all runtime files and fonts through this source admission prerequisite.
- Record the completed installed-pin verification from Studio PR #10. Adopt
  the pinned owner's public favicon, font, icon, lockup, logo, and social asset
  exports, then remove the 64 matching Studio source copies. Preserve every
  generated output path, byte, mode, and font notice.
- Extend that public asset mapping to the complete 80-file motif and 12-file
  template families. Remove 41 exact motif copies in a bounded slice and stop
  invoking local motif generation from the retained consistency checker.
  Preserve all 238 output paths and modes and every rendered/runtime byte.
  Only the emitted raw checker script changes to reflect that removed check;
  the other 237 output files remain exact. Keep the remaining 51 motif/template
  copies for the next bounded source deletion.
- Remove those last 39 motif and 12 template copies in that next slice, totaling
  2,223,201 source bytes. The public families already supply output, so preserve
  the resolver, generators and every emitted file byte for byte with its
  existing mode. Update current guides without editing rendered references.
- Keep the remaining owner adoption, live legacy kit retirement, and browser
  verification open. Each later slice still needs normal human admission,
  both complete AI reviews, and every protected check.

## Capabilities

### New Capabilities

- `studio-site-output`: Defines the static output boundary, retired downloads,
  retained live assets, and local verification of the Studio site.

### Modified Capabilities

None. This checkout has no existing main specs.

## Impact

`ejmlabs` owns Studio content and public output assembly. `ejm-ui` owns shared
tokens, components, and site infrastructure. Later adoption must consume pinned
public owner exports without copied implementations or private imports.

The output phase changes the static build, gallery, docs, and output tests.
The source admission prerequisite changes only workflow callers, static review
data, the UI source manifest, guides, and this plan. The next asset slice changes
Studio assembly and its existing output check, consumes public owner exports,
and removes matching local copies without rotating callers or source pins.
It adds no dependency or service. It removes archive work from each build and
must stay below the existing 200-file, 12,000-line, and 1,000,000-byte PR bounds.
Local checks do not establish hosted CI, deployment, or publication.
