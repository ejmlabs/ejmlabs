projects

A coding agent engine, and two ways to use it.

ejm-harness is the engine. ejm-cli and ejm-ide are separate apps built on it. All three are open source under the MIT license.

TerminalRustMIT

ejm-cli

A coding agent for your terminal.

It streams the conversation, saves sessions, and lets you steer a running turn. File tools are read only until you grant write or shell access, and the grants stay visible on screen.

built on ejm-harness

cli.ejmlabs.com

DesktopTauriReactRustMIT

ejm-ide

A desktop IDE with an agent beside the editor.

Write and understand code with navigation, call graphs and Git history, next to a chat that shows each tool call and the diff it made. It starts on macOS with Apple Silicon.

built on ejm-harness

ide.ejmlabs.com

EngineRustTypeScriptPythonMIT

ejm-harness

A reusable Rust engine for coding agents.

Run many sessions through one resource governor, keep a durable event journal, and extend the engine from Rust, TypeScript or Python.

powers ejm-cli and ejm-ide

harness.ejmlabs.com

sessions

Read, list, search, write and patch, with optional shell access.

how we work

Three habits.

  1. Start small.

    Each experiment answers one question, so it can be built, tried and judged quickly.

  2. Make it useful.

    A project is finished when someone can use it, not when it is clever.

  3. Share the tools.

    What we build for ourselves, we release as open source so others can build on it.
