# ejmlabs brand kit

Approved ejmlabs and project artwork for use with the accompanying rights notice.
Read `RIGHTS.md` and `LICENSE` before using or redistributing these files.
Downloading the kit does not grant a new license to the artwork or marks.

## Choose a file

- `logos/ejmlabs-primary.svg` is the full ejmlabs logo for light backgrounds.
  Use `ejmlabs-ink.svg` for one-color dark artwork and `ejmlabs-paper.svg` on a
  dark background.
- `logos/symbol-*.svg` contains the standalone symbol for a small space where
  the ejmlabs name is already clear. Use the full logo when introducing ejmlabs.
- `projects/cli`, `projects/ide` and `projects/harness` contain each project's
  horizontal logo, standalone mark, square icons, favicons and social card.
  `logo-primary.svg` is the default on a light background; `logo-paper.svg` is
  for a dark one. `mark-*` files contain only the project mark.
- SVG files directly inside those folders have outlined artwork and need no
  installed font. Matching PNGs are for tools that cannot import SVG.
  `editable/` versions use live text and need the supplied Manrope font.
- `lockups/` pairs the symbol with a decorative signature. `motifs/` contains
  Flow, Orbit and signature crops. Neither replaces the complete logo.
- `social/` contains avatar and social-card exports. `templates/` contains
  starting layouts; replace sample copy and imagery before publishing.
- `favicon/` contains the prepared browser and app icon sizes. Preserve each
  canvas. Use the supplied small favicon rather than shrinking the full logo.
  These icons use the ejmlabs symbol in Ink on Sage. The project folders contain
  each project's own mark in the same treatment.

Keep every mark's proportions, drawing and spacing. Do not redraw it, retype the
wordmark, stretch it or add effects. Choose a supplied color variant with enough
contrast against its background.

## Clear space

Leave at least half the symbol's height clear on every side of the full ejmlabs
logo. Around the standalone ejmlabs symbol, leave one quarter of its width.

For project logos, leave half the mark's height around the horizontal logo and
one quarter of the mark's width around a standalone mark. Square icons, avatars
and favicons include their clear space; keep their canvas intact. Other SVG view
boxes fit the artwork, so add the clear space outside the file.

## Color and type

`palette.json` lists the five brand colors and measured contrast pairs. Sage
(`#8A9A7B`) leads; Forest (`#29443B`) is an accent. Ink (`#202721`), Paper
(`#F6F5EF`) and Mist (`#E8EDE3`) carry text and surfaces. Sage on Paper does not
meet WCAG AA for normal text. Use Ink on Paper or Sage, Paper on Forest, or
Forest on Mist for normal text.

Manrope is the text family, normally at weights 400 and 600. IBM Plex Mono Medium
is for code, versions and short labels. Complete TTF and WOFF2 files are in
`fonts/`, with the original SIL Open Font License notices. Keep those notices
with redistributed font files. The vector wordmarks are artwork, not typed text.
